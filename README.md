# Academic Tracker CLI 📚

Herramienta de consola desarrollada en **Java** para la gestión de asignaturas, registro de evaluaciones y cálculo automático de notas ponderadas. Proyecto personal enfocado en buenas prácticas de ingeniería de software, arquitectura limpia y control de versiones.

## 🚀 Características
- **Gestión de Asignaturas:** Añade y consulta el estado de tus materias.
- **Cálculo Ponderado:** Calcula la nota final en base a los porcentajes de cada prueba.
- **Persistencia en Disco:** Los datos se guardan automáticamente en un archivo de texto (`academic_data.txt`) al cerrar la sesión.
- **Arquitectura Limpia:** Código estructurado en capas (`model`, `service`, `cli`).

## 🛠️ Tecnologías
- **Lenguaje:** Java
- **Entorno:** IntelliJ IDEA
- **Control de versiones:** Git / GitHub
